# Conclusion

## Final Thoughts

Overall, I'm very happy with the outcome of this project. While challenging, I was able to use design skills I haven't gotten to practice as much in other projects. Getting to combine skills from both my UX/UI and Communications classes into a project and documentation site was something I found I enjoyed.

My main takeaway was being able to take parts of an existing design forward in a redesign. In many cases, existing designs aren't always fully bad. There's often design elements that work on their own, and look worse due to elements they're surrounded by. Being able to pick these out was not only a useful skill, but also realistic. In real redesign projects, keeping some similarity to the old design helps a large change feel less jarring to users.
